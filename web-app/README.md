# web-app

The Astro static site for **Dani's Backyard**. See the [root README](../README.md) for the full project overview, content pipeline, and deployment details.

## Quick start

```bash
npm install
npm run sync    # copy vault content into src/content/
npm run dev     # start dev server at localhost:4321
```

## Scripts

| Command | Purpose |
| :--- | :--- |
| `npm run dev` | Dev server at `localhost:4321` |
| `npm run build` | Build static site to `dist/` |
| `npm run sync` | Copy vault content → `src/content/` + `public/_attachments/` |
| `npm run preview` | Preview production build locally |
