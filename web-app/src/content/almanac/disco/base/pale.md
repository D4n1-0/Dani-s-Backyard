# Pale

*The separative tissue between the Isolas. Grey, expanding, antimemetic — it unmakes matter and memory alike. Crossing the Pale is possible but dangerous; prolonged exposure erodes identity. Radio waves can penetrate it, which is how the Isolas communicate. Some say the Pale is a byproduct of human consciousness. Others say it is God's unfinished work. Most try not to think about it while they still can.*
