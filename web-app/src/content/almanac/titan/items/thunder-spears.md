# Thunder Spears

## Description
Rocket-propelled explosive lances fired from [[Omni-Directional Mobility Gear]] mounts. Each carries a shaped-charge warhead designed to punch through hardened Titan armour — the first Paradis weapon capable of damaging the Armored Titan. Crude but effective: requires a timed fuse pull before launch, demanding suicidal-close engagement range.

## Function
Anti-armour weapon. Used decisively against [[Reiner Braun|Reiner]]'s Armored Titan at Shiganshina. Limited ammunition — each soldier carries only a handful. The shaped charge detonates on impact, creating a secondary internal explosion. Dangerous to the user as well as the target.

## History
Developed by the Survey Corps in response to the Armored Titan's near-invulnerability to blades. Represents Paradis's first step toward anti-Titan weapons beyond swords. In modern military terms, roughly equivalent to early WWII-era anti-tank rockets.
