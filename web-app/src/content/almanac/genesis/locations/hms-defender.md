# *[[HMS Defender|HMS Defender]]*

## Overview
A Type 45 destroyer of the modern [[Royal Navy (Modern)|Royal Navy]]. Second ship of the three-vessel response to [[The Anomaly]], operating alongside *[[HMS Dragon|HMS Dragon]]* and *[[HMS Duncan|HMS Duncan]]*.

## Features
- Sea Viper missile system (cold but ready)
- Modern communications and radar suite

## Inhabitants
Standard modern RN complement.

## Current Events
Holding station at [[The Anomaly]] as part of the three-ship standoff.
