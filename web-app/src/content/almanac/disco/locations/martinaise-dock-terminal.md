# Martinaise Dock Terminal

## Overview

*A cathedral of industry gone quiet. Loading bays gaping open, pallets stacked in towers, freight still strapped and unmoved. Strike graffiti layers the walls — ALL WORKERS ARE BOARD, CLAIRE BROTHERHOOD — over older messages from previous disputes. The air is cold and tastes of rust and dead diesel. Previously controlled by striking dockworkers; reclaimed by Coalition forces on behalf of Wild Pines.*

## Features

- Main loading floor — cavernous, echo-prone, pigeons in the rafters
- Old supervisor's office — designated control room for the new security system
- Perimeter — unguarded since the Coalition withdrawal at 16:00

## Inhabitants

- [[Lukas Delacroix]] — Wild Pines engineer, installing the security apparatus
- [[INSURCOM]] — Temporary presence, withdrawn after reclamation

## Current Events

*Under Wild Pines control. Security system installation pending.*
